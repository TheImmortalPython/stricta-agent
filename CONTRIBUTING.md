# Contributing to Stricta

Stricta is a solo-authored project maintained by Joshua St. Germain (TheImmortalPython Labs).

## Pull Requests

Third-party pull requests are not currently accepted. Development and release changes are authored and reviewed directly by the maintainer.

## Issues and Feedback

Bug reports, reproducible test cases, and technical feedback are welcome via GitHub Issues. When opening an issue, please include:

- Python version and relevant environment details
- Minimal reproduction steps or smoke-test context
- Expected behavior vs. actual behavior
